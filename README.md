# 7 a 0 — Copa do Brasil Edition

Jogo de futebol em turnos que roda no navegador, sem instalar bibliotecas.

## Jogar

Abra o GitHub Pages deste repositório, ou abra `index.html` diretamente no navegador.

## Executar localmente

Se preferir usar um servidor local, abra um terminal nesta pasta e rode:

```powershell
python -m http.server 8000
```

Depois, acesse `http://localhost:8000`.
